# salon-booking-demo

Демо чат-бота онлайн-записи для салонов красоты.

Интерактивное демо: бот записи клиентов, панель администратора, график мастеров, Google Календарь.

Откройте: https://rawefy.github.io/salon-booking-demo/

Персонализация под салон — параметрами в ссылке: `?salon=Название&addr=Адрес`

Пример: https://rawefy.github.io/salon-booking-demo/?salon=Чародейка&addr=ул. Республиканская, 25
